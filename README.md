One original line, at most 160 characters: a software patch note for a bug in real life / human biology, in the terse register of a real release note. Pure standard library Python; deterministic — the same line on every run.

## Run it

```sh
python3 main.py
```

The program writes the patch note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
